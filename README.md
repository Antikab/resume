# Резюме Арсения Просветова

Сайт и документы для вакансий **Frontend Engineer — Vue 3 / TypeScript**. Стек самого сайта: Vue 3, Vite, JavaScript, SCSS. Содержание актуализировано в сентябре 2026 года.

## Запуск

Нужны Node.js 22+ и Yarn 1. Зависимости и версия Playwright фиксируются в `yarn.lock`.

```bash
yarn install --frozen-lockfile
yarn dev
```

`dev` запускает сайт. Он не пересоздаёт документы при каждом изменении компонента.

## Документы для отклика

В `public/resume/` лежат готовые PDF, HTML и TXT. Они входят в `dist` без отдельного backend. HTML открывается с отключённым JavaScript. PDF — двухстраничный A4 с текстом, а не снимками экрана. Публичные примеры небольших проектов остаются на сайте; документы содержат основные рабочие проекты полностью.

После изменения содержания или печатного CSS:

```bash
# Один раз для установки браузера:
yarn browser:install

# Обновить HTML, TXT, PDF и манифест:
yarn resume:pdf

yarn verify
```

`resume:pdf` печатает HTML через Playwright / Chromium с тем же CSS. Python и отдельная PDF-вёрстка не нужны. Сети и локального веб-сервера для генерации нет. Копия результата сохраняется в `output/pdf/` для просмотра.

`yarn resume:export` обновляет только HTML и TXT; эту команду удобно использовать во время правки документа. `yarn build` проверяет соответствие готового PDF HTML, CSS, коду рендерера и версии Playwright, а также целостность самого файла. Устаревший или отсутствующий PDF блокирует сборку с командой исправления. Обычная сборка не запускает Chromium, поэтому установка браузера в окружении деплоя не требуется. В Git необходимо сохранять PDF и его `.manifest.json` вместе с исходными изменениями.

По умолчанию используется Chromium версии, соответствующей Playwright. Для локальной диагностики можно задать `PDF_BROWSER_CHANNEL=chrome yarn resume:pdf`. Системный браузер и доступные шрифты могут изменить переносы; после смены окружения проверяйте страницы визуально. Манифест проверяет актуальность артефакта, но не обещает побайтово одинаковый результат в разных ОС.

## Дипломы

Оригинальные PDF находятся в `public/documents/education/`. В данных используются URL `/documents/education/...pdf`, без префикса `/public`. Ссылки открывают документ в новой вкладке, без Google Drive и без атрибута `download`. Конкретное поведение PDF-просмотра зависит от настроек браузера посетителя.

При замене диплома обновите файл и сведения в `src/content/education.js`. Экспорт проверяет допустимый локальный путь, наличие файла и PDF-сигнатуру. В эти каталоги добавляются только документы, предназначенные для публичного сайта; выписка о трудовой деятельности в проект не копируется.

## Проверки

```bash
yarn verify        # ESLint, Node-тесты, проверка актуальности PDF и production build
yarn format:check  # форматирование без изменения файлов
yarn test:browser # после build и browser:install
yarn preview      # ручная проверка production-сборки
```

Браузерная проверка поднимает собственный локальный preview и закрывает его после выполнения. Проверяются ширины 360, 390, 768, 1024 и 1440 px, раскрытие проектов клавиатурой, контакты, ответы файлов, дипломы и HTML без JavaScript. Скриншоты сохраняются в `output/resume/`.

После изменения печатной вёрстки дополнительно проверьте PDF визуально и извлечение текста. При установленном Poppler:

```bash
pdfinfo public/resume/arseniy-prosvetov-frontend-2026.pdf
pdftotext -layout public/resume/arseniy-prosvetov-frontend-2026.pdf -
pdftoppm -png public/resume/arseniy-prosvetov-frontend-2026.pdf /tmp/resume-page
```

## Публикация

Сборка: `yarn build`, каталог: `dist`. Сайт рассчитан на размещение в корне домена. Папки `output/` и `tmp/` не публикуются и не входят в Git. Команда `build` не выполняет деплой. [Опубликованный сайт](https://resume-proars.vercel.app/) получит изменения после отдельной публикации.
